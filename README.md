**Diablo AI — Python Desktop Voice Companion & Automation** is a production-grade **AI & Desktop Voice Automation** meticulously crafted with modern development standards, high performance, and smooth responsiveness.

## ⚡ Quick Start & Local Setup

### 1. Clone the Repository
```bash
git clone https://github.com/pasha804/diablo-ai-voice-assistant.git
cd diablo-ai-voice-assistant
```

### 2. Launch Locally
Launch directly in any modern browser:
```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

Or spin up an instant local web server:
```bash
npx serve .
# or
python -m http.server 8080
```
